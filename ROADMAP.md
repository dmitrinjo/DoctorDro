# DoctorDro — Roadmap

> Живой документ. Обновляется по мере выполнения этапов.
> Язык разработки: русский (UI будет мультиязычным с Milestone 3).

## Общая картина

```
M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8
Фун  Стаб  Дан  i18n  LV   AI   Фичи  Моб  Скейл
```

Первые два milestone — фундамент. Без них добавлять фичи опасно.
Milestone 3–4 — адаптация под рынок.
Milestone 5–6 — то, что делает продукт уникальным.
Milestone 7–8 — рост за пределы одной семьи.

## Milestone 6 — Killer Features

**Цель:** Фичи, которых нет ни в одном другом медтрекере.

### 6.2 Проверка взаимодействия препаратов 💊
- [ ] При добавлении нового препарата → Claude проверяет против текущего списка
- [ ] Использовать публичную базу: DrugBank API или OpenFDA
- [ ] Предупреждение в UI: "Препарат X несовместим с Y (принимается сейчас)"
- [ ] Уровни: информация / предупреждение / критично
- **Почему killer:** это делают дорогие фармацевтические системы, не домашние трекеры

### 6.3 Подготовка к визиту врача 📋
- [ ] Кнопка "Подготовиться к визиту" на карточке специалиста
- [ ] Claude генерирует: краткую историю, текущие препараты, список вопросов к врачу
- [ ] Экспорт в PDF или текст для распечатки
- [ ] На русском / латышском по выбору
- **Почему killer:** врачу сразу видна вся картина, экономит 10 минут приёма

### 6.4 Временная шкала здоровья 📈
- [ ] Интерактивный график: ось X = время, ось Y = показатель
- [ ] Несколько показателей на одном графике (например, ферритин + гемоглобин)
- [ ] Отметки событий: визит, смена препарата, диагноз
- [ ] Видно: как менялся показатель после назначения лечения
- **Почему killer:** ни одна лаборатория не показывает динамику за годы

### 6.5 Семейный доступ (read-only)
- [ ] Пригласить второго члена семьи: жена/муж видит данные, не может редактировать
- [ ] Уведомление при любом изменении данных
- [ ] Отдельный PIN для гостевого доступа
- **Почему killer:** для семей где медицинскими вопросами занимаются оба родителя

### 6.6 Рейтинг специалистов
- [ ] После каждого визита: краткая оценка (1–5) + заметка
- [ ] Поле "доверие к этому врачу" с историей
- [ ] Claude автоматически отмечает: следовал ли врач доказательной медицине
- [ ] Личный список "рекомендуемых" и "не возвращаться"
- **Почему killer:** решает исходную проблему автора ("как понять профессионал перед тобой или нет")

**Definition of Done M6:** Проверка препаратов работает, подготовка к визиту генерируется.
